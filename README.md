# Nourish Navigator

Product Context

I am building a personalized food scanning app that helps users understand how a packaged food fits their individual nutrition goals.

Unlike apps that mainly classify foods as “good” or “bad,” this app should provide practical, personalized guidance based on the user's selected goal, explain the factors influencing the recommendation, and help the user make a more informed choice.

The product should feel simple, supportive, trustworthy and non-judgmental.
